# Carpeta de entrada

Subí acá tu PDF (por ejemplo `mi-libro.pdf`). Al hacerlo, GitHub Actions lo
convierte solo y te deja el `.epub` para descargar en la pestaña **Actions**.

- Desde el celular: en github.com → esta carpeta → **Add file → Upload files**.
- El EPUB aparece como "Artifact" al final de la corrida (pestaña Actions).

Nota: si tu repositorio es **público**, no subas libros con copyright acá
(quedarían en el historial). Usá un repo **privado**, o el botón *Run workflow*
con una URL directa al PDF (así no se guarda en el repo).
